# 231011400411_M.KhoerulRamadan_06Tple008_MP_2026

## 1. Sketsa Layout

Tampilan aplikasi menggunakan `Scaffold` sebagai halaman utama, `AppBar` untuk judul halaman, `ListView` agar bisa discroll, serta `Card` dan `Column` untuk menyusun informasi workshop secara rapi dari atas ke bawah.

## 2. Alasan Pemilihan Widget
Widget dipilih sesuai fungsi tampilannya, seperti `ListView` untuk menampilkan banyak data, `Card` agar informasi terlihat terpisah, dan `Column` untuk menyusun isi workshop secara vertikal sehingga lebih mudah dibaca.

## 3. Kesalahan UI yang Ingin Dihindari
Kesalahan yang dihindari adalah tampilan terlalu penuh dan jarak antar komponen terlalu rapat karena dapat membuat pengguna kesulitan membaca informasi.

## 4. Kenyamanan Baca (UX)
Kenyamanan baca dibuat dengan memberi jarak antar komponen, menggunakan ukuran teks yang jelas, menyusun informasi secara urut, dan membuat tampilan sederhana agar pengguna lebih nyaman melihat isi aplikasi.
